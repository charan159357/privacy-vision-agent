How it works
① Capture — the page is rendered to a canvas on-device (no screenshot service).
② Local vision — DOM structure analysis (autocomplete/labels/values) + YuNet face detection via ONNX Runtime Web on WebGPU → WASM.
③ Redact — faces blurred, passwords/OTP blacked out, PII masked with a deterministic strategy; pixel & byte delta audited.
④ Privacy gateway — a fetch/XHR guard re-scrubs any outgoing payload (defense in depth).
⑤ Server brain — the sanitized screenshot + element map go to a planner (cloud LLM/VLM if a key is set, deterministic fallback offline) which returns commands.
⑥ Execute — click / type / scroll… run locally until the task completes.
